# Foxcore Retail 销售管理系统分析与设计

## 项目简介

Foxcore Retail 销售管理系统面向音乐节、展会等活动现场的商品销售场景，围绕销售记录录入与销售业绩查询开展业务建模、需求分析、系统分析和数据库设计。

系统旨在改善现场销售依赖纸质记录、事后人工汇总所带来的记录遗漏、统计效率低及数据难以追溯等问题，为销售数据的统一管理与后续系统实现提供设计依据。

## 业务范围

- **录入销售**：销售顾问在对应班次内录入商品、销售数量和成交总金额，由系统校验相关信息并保存销售记录。
- **查询销售统计**：管理者按销售顾问、商品、活动等维度查询和汇总销售情况。

## 系统分析与数据库设计

系统以销售记录为核心，涉及销售顾问、商品、活动、展位、班次和销售等业务概念。

主要关系如下：

- 一场活动可设置多个展位，每个展位归属于一场活动。
- 一个展位可安排多个班次，每个班次关联一名销售顾问和一个展位。
- 一个班次可产生多笔销售，每笔销售对应一个班次和一种商品。
- 商品可出现在多笔销售中。

数据库设计通过主键唯一标识记录，通过外键关联相关数据表。销售记录保存商品、数量、成交总金额及成交时间；销售顾问、展位和活动信息可通过班次及其关联关系追溯。

销售录入遵循商品有效、数量为正整数、班次有效等规则；成交总金额应不低于商品最低单价与销售数量的乘积。
