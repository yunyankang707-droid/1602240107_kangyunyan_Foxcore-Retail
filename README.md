## 二、系统简介

Foxcore Retail 销售管理系统面向音乐节、展会等现场零售场景，主要用于管理商品销售业务，实现销售记录录入、销售数据查询及经营情况统计等功能。

系统设有两种用户角色：

- **管理者：** 负责系统管理、业务数据查询及销售统计。
- **销售顾问：** 负责日常销售记录录入及相关信息查看。

## 三、主要功能

### 管理者功能

管理者可以通过后台查看和管理销售业务数据，包括销售记录、商品、销售顾问、活动及相关统计信息。主要功能包括经营仪表板、销售记录查询、销售数据统计、活动经营分析及基础数据查看。

### 销售顾问功能

销售顾问可以进入销售工作界面，查看本人销售指标和近期销售记录，依据当前有效班次录入销售记录，并查看本人相关销售明细及日常工作所需的商品、活动、场地和展位资料。
